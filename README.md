# Calcora

A clean, responsive browser calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication, division, and percentages
- Parentheses, decimal values, and positive/negative number input
- Live result preview as you type
- Recent calculation history stored locally in your browser
- Light and dark themes
- Keyboard input, including Enter to calculate, Backspace to edit, and Escape to clear
- Safe expression parsing without JavaScript \`eval()\`
- Responsive layout and accessible labels
- No runtime dependencies or build step

## Run locally

Open \`index.html\` in a modern browser. No build step or dependencies are required.

## Run tests

Requires Node.js 18 or newer:

\`\`\`bash
npm test
\`\`\`

## Privacy

Calculations and theme preferences are stored in the browser's local storage. No account or server is required.
