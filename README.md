# JavaScript Calculator

A lightweight browser calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Parentheses, decimal values, and unary plus/minus
- Keyboard input, including Enter to calculate, Backspace to edit, and Escape to clear
- Safe expression parsing without JavaScript `eval()`
- Responsive layout and accessible labels

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Run tests

Requires Node.js 18 or newer:

```bash
npm test
```
